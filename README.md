# StreetWearLab — модули оформления заказа и отзывов

Курсовой проект «Технологии разработки программных комплексов», ИРНИТУ.
Автор: Ковалев В.В.

Интернет-магазин уличной одежды StreetWearLab. В проекте реализованы:

- **оформление заказа**: состав заказа, адрес доставки, способ доставки (СДЭК, Почта России, Boxberry, самовывоз), способ оплаты (картой, СБП, наличными), расчёт итоговой суммы, проверка остатков, создание заказа с номером `ORD-…`, очистка корзины;
- **история заказов** и страница деталей заказа;
- **отзывы**: выставление оценки 1–5 звёзд и текст отзыва для позиций доставленного заказа, проверка права на отзыв;
- **модерация отзывов** администратором: вкладки «Ожидают / Одобрены / Отклонены», одобрение и отклонение, пересчёт рейтинга товара;
- блок отзывов и рейтинга на странице товара, уведомления.

Каталог, корзина и авторизация реализованы в упрощённом виде (они относятся к смежной курсовой работе) — ровно настолько, чтобы можно было показать работу модулей целиком.

## Стек

| Часть | Технологии |
|---|---|
| Фронтенд (`artifacts/client`) | React 18, Vite, TanStack Query, wouter |
| Бэкенд (`artifacts/api-server`) | Node.js, Express 5, JWT |
| Слой доступа к данным (`lib/db`) | Drizzle ORM, SQLite (LibSQL) |

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install        # установка зависимостей всех пакетов монорепозитория
npm run db:seed    # создание базы streetwearlab.db и демонстрационных данных
npm run dev        # API на http://localhost:3001, сайт на http://localhost:5173
```

Откройте http://localhost:5173.

Демо-учётные записи:

- клиент — `client@demo.ru` / `123456` (в корзине уже есть товары, есть доставленные заказы для отзывов);
- администратор — `admin@demo.ru` / `admin123` (модерация отзывов, смена статусов заказов).

Чтобы начать с чистыми демо-данными, ещё раз выполните `npm run db:seed`.

## Сценарий демонстрации

1. Войти как клиент → корзина → «Оформить заказ» → выбрать доставку и оплату → подтвердить.
2. «Мои заказы» → доставленный заказ → «☆ Отзыв» → выставить оценку, написать текст → «Отправить отзыв».
3. Выйти, войти как администратор → «Отзывы» → одобрить отзыв → открыть товар и увидеть отзыв и новый рейтинг.
4. Администратор → «Заказы» → перевести новый заказ клиента в «Доставлен», чтобы на него тоже можно было оставить отзыв.

## Структура

```
lib/db/src/schema/        таблицы Drizzle: users, products, cart, orders, reviews, notifications
lib/db/src/seed.ts        демонстрационные данные
artifacts/api-server/src/
  lib/auth.ts             requireAuth, requireRole
  routes/orders.ts        POST /orders, GET /orders, GET /orders/:id, POST /orders/:id/pay
  routes/reviews.ts       POST /reviews, GET /products/:id/reviews, GET /orders/:id/reviews
  routes/adminReviews.ts  GET /admin/reviews, PATCH /admin/reviews/:id/approve|reject
artifacts/client/src/
  pages/Checkout.tsx      страница оформления заказа
  pages/OrderDetails.tsx  детали заказа и форма отзыва
  pages/AdminReviews.tsx  модерация отзывов
  lib/api.ts              клиент API и хуки TanStack Query
```
